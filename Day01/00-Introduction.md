## 📌 Summary | 요약
- Swift is a modern, safe, and clear language launched by Apple in 2014.
- Swift는 2014년 애플이 발표한 현대적이고 안전하며 읽기 쉬운 언어다.
- SwiftUI is Apple's framework for building UI with Swift.
- SwiftUI는 Swift로 화면(UI)을 만드는 애플의 프레임워크다.
- This course focuses on practical, frequently used features rather than theory.
- 이 강의는 이론보다 실제로 자주 쓰는 기능 위주로 실습 중심으로 진행된다.

## 📖 Key Concepts | 핵심 개념

### 1. Why Swift? | 왜 Swift인가?
- **Practical reason | 현실적인 이유**: You can build and sell apps on the App Store.
  App Store에 앱을 출시해 수익을 낼 수 있다.
- **Young language (2014) | 비교적 새로운 언어**: Less legacy "cruft", usually one clear way to solve a problem.
  오래된 언어처럼 불필요한 잔재가 적고, 보통 문제를 푸는 방법이 하나로 명확하다.
- **Learned from older languages | 기존 언어의 장단점을 반영**
  - Hard to write unsafe code by accident → 실수로 안전하지 않은 코드를 쓰기 어렵다
  - Easy to write clear, readable code → 명확하고 읽기 쉬운 코드를 쓰기 쉽다
  - Supports all world languages (Unicode) → 모든 언어 문자를 지원해 깨진 문자 오류가 없다

### 2. Swift vs SwiftUI
| | Swift | SwiftUI |
|---|---|---|
| What | Programming language | UI framework |
| 역할 | 프로그래밍 언어 (로직) | 화면 구성 (텍스트, 버튼, 이미지, 사용자 상호작용 등) |

- Swift itself doesn't draw anything on screen.
  Swift 자체는 화면에 아무것도 그리지 않는다.
- SwiftUI is built specifically for Swift, using its power and safety to build apps quickly.
  SwiftUI는 Swift를 위해 만들어져 Swift의 장점을 살려 빠르게 앱을 만들 수 있다.

## 🛠️ Setup | 실습 환경
- **Xcode 15.0 or later** (free on the Mac App Store)
  Xcode 15.0 이상 설치 (Mac App Store 무료)
- Create a Playground | 플레이그라운드 만들기:
  1. Launch Xcode | Xcode 실행
  2. `File` → `New` → `Playground`
  3. `macOS` tab → `Blank` 선택
  4. Save it somewhere easy to find | 찾기 쉬운 곳에 저장
- Playground = a sandbox to run Swift code and see results side by side.
  플레이그라운드는 코드와 실행 결과를 나란히 보며 바로 테스트할 수 있는 연습 공간이다.
- 💡 Tip: The first run may take a few seconds; later runs are fast.
  첫 실행은 몇 초 걸릴 수 있지만 이후에는 빠르다.
